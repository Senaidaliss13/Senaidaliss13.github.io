Automatización y clasificación de correos con n8n

Desarrollo de un workflow automatizado para recibir correos electrónicos, analizar su contenido mediante inteligencia artificial y clasificarlos según el nivel de atención requerido, permitiendo que cada mensaje siga una ruta específica dentro del flujo.

n8n Gmail AI Agent Workflow Automation Conditional Logic

Objetivo del proyecto

Automatizar la clasificación inicial de correos electrónicos para reducir la revisión manual y permitir que los mensajes sean procesados de forma distinta dependiendo de su contenido y prioridad.

Qué desarrollé

  • Configuración de un trigger para detectar nuevos correos.
  • Obtención del contenido completo de cada mensaje.
  • Análisis del correo mediante un agente de inteligencia artificial.
  • Clasificación automática de los mensajes según criterios definidos.
  • Uso de condiciones para dirigir cada correo a una ruta diferente.
  • Pruebas con diferentes tipos de mensajes para validar el comportamiento del flujo.

Flujo de trabajo

El proceso fue estructurado en diferentes etapas para recibir, analizar y clasificar automáticamente los correos.

PASO 01

Recepción del correo

El workflow inicia automáticamente cuando se detecta un nuevo mensaje de correo electrónico.

PASO 02

Obtención del mensaje

Se recupera el contenido necesario del correo para que pueda ser utilizado por los siguientes nodos.

PASO 03

Análisis con IA

Un agente de inteligencia artificial analiza el contenido y determina la clasificación correspondiente.

PASO 04

Decisión automática

Mediante lógica condicional, el flujo dirige el mensaje hacia la ruta correspondiente según el resultado del análisis.

Herramientas utilizadas

Resultado

El workflow quedó funcional para recibir, analizar y clasificar automáticamente correos electrónicos, ejecutando diferentes rutas según el tipo de mensaje identificado.

Qué aprendí

  • Configuración y uso de triggers.
  • Integración de Gmail dentro de un proceso automatizado.
  • Transferencia de información entre diferentes nodos.
  • Uso de agentes de IA para clasificación de contenido.
  • Aplicación de lógica condicional mediante nodos IF.
  • Pruebas y validación de diferentes rutas dentro de una automatización.
